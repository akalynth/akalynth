# Promotion Preconditions

Before any high-city authority bundle can become runtime/shared map data, a future promotion gate must prove all of the following:

1. The runtime map schema has been accepted.
2. Every referenced input receipt is accepted.
3. Every layer artifact hash matches its accepted candidate or explicitly reviewed projection.
4. Coordinate systems and bounds are compatible.
5. Collision and walkability conflicts are zero.
6. Door/house records resolve only accepted reserved door/threshold candidates.
7. Transition records resolve only accepted reserved transition candidates.
8. Destination maps or regions exist before any runtime transition is enabled.
9. Ownership/access/lock behavior has separate accepted runtime evidence before enforcement.
10. Shared map JSON changes are isolated and reviewed.
11. Server movement behavior is verified by runtime tests.
12. Client presentation remains separated from server authority.
13. Negative authority leakage cases are executable and pass.

This design gate does not satisfy those conditions. It only records them.
