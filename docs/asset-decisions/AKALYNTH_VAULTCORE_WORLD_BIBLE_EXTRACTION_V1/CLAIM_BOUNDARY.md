# Claim Boundary

## Accepted Narrow Claim For This Lane

The COSMIC_ROOT/VaultCore civilization material has been extracted into Akalynth world bible documents as source mythology translated into game-facing lore.

## What Is Proven

- VaultCore civilization source exists and was inspected from the durable extraction-only clone.
- High City is framed as the first city of Akalynth.
- VaultCore Prime is preserved as the old/source name for High City in deep lore.
- Dreamforged, Flamebound, and Codexborn are mapped into Akalynth as lore orders/factions by default.
- Myths, rites, doctrines, sacred numbers, districts, and profession ideas are recorded as future design seeds.
- System/cosmic language is translated into game-facing MMO language.

## Explicit Non-Claims

This lane does not:

- execute VaultCore scripts
- import COSMIC_ROOT code
- import VaultCore configs into runtime packages
- rename Azura in runtime
- modify `packages/shared/maps/*.json`
- modify shared protocol
- modify shared types
- modify server movement, collision, walkability, NPCs, mobs, shops, economy, quests, ownership, or transitions
- create playable species, classes, origins, or faction reputation
- implement puzzles, rituals, trials, crafting, prophecy, law, or archive mechanics
- promote High City into a production map
- deploy anything

## Runtime Reality

Runtime Akalynth may still refer to Azura in maps, docs, tests, Android assets, type names, tutorial gates, property ids, and examples. This lane intentionally does not change those references.

## Required Future Gates

Before this world bible becomes production-facing runtime content, use separate lanes for:

1. High City canonical world decision
2. Azura-to-High-City naming migration design
3. runtime map id strategy
4. Rookguard gate target strategy
5. faction/origin gameplay design, if desired
