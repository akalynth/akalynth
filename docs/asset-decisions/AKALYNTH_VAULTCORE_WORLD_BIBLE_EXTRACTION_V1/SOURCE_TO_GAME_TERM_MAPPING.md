# Source-To-Game Term Mapping

## Purpose

This mapping keeps VaultCore source authorship while making Akalynth readable as a classic MMO world.

## Canonical Mappings

| VaultCore term | Akalynth game-facing term |
| --- | --- |
| VaultCore Prime | High City, old name preserved in deep lore |
| VaultCore civilization | old orders of High City |
| consciousness | memory, spirit, will, awareness, living witness |
| consciousness resonance | echo, omen, shrine response, city memory |
| recursive architecture | repeating towers, mirror halls, echo corridors |
| mythic patterns | old signs, sigils, recurring city marks |
| ritual | ceremony, quest, shrine interaction, oath, trial |
| rite | public ceremony or future quest step |
| awakening | calling, first oath, first memory, first vision |
| sacred law | oath, city law, archive record |
| law binding | oath sealing, bronze tablet, written mark |
| evolution | growth, trial, remaking, reputation in lore |
| transformation | forge trial, name-burning, remaking |
| species | order, faction, bloodline, school, people, or mythic kin |
| cognitive model | temperament, tradition, order discipline |
| consciousness field | atmosphere, shrine aura, district reputation |
| economic foundation | market lore seed only |
| VaultCredit | do not import |
| VaultBond | do not import |
| MythMint | do not import |
| API / mesh / executor language | do not import into game lore |

## Naming Rules

Use:

- High City
- Dreamforged
- Flamebound
- Codexborn
- Dream Sanctums
- Emberworks
- Scroll Sanctums
- Crown Plaza
- Lower Drain

Avoid in player-facing copy unless deliberately framed as ancient/source terminology:

- VaultCore
- computation
- digital realm
- consciousness framework
- execution
- API
- classifier
- mesh
- automation

## Example Rewrites

Original source direction:

> Consciousness resonance and recursive architecture.

Akalynth form:

> The Dreamforged built towers that echo memory. Walk too deep and the city repeats your steps before you take them.

Original source direction:

> Law Binding Forges.

Akalynth form:

> The Codexborn seal oaths into bronze tablets. Breaking one marks the soul with a visible sigil.

Original source direction:

> Transformation Forge.

Akalynth form:

> The Flamebound burn old names from steel and flesh alike. Their trials remake cowards into champions, or ash.

## Non-Claim

This mapping does not rename runtime files, change copy in the app, or create live lore.
