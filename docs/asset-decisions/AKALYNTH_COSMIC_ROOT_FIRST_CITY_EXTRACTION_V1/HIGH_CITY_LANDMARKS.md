# High City Landmarks

## Purpose

This document names the landmark set that should guide later visual layout, map metadata, and production promotion candidates.

These are design targets only.

## Landmark List

| Landmark | Role | Source inspiration | Current authority |
| --- | --- | --- | --- |
| High Gate | first-city entry point | city boundary / formal entry | none |
| Crown Plaza | central public meeting space | convergence center | none |
| Plaza Fountain | visual center and rest point | public center | none |
| Notice Board | task and message flavor | exchange / assembly | none |
| Lantern Archive | records and chronicle flavor | scroll sanctums / archives | none |
| Proof Desk | proof and receipt flavor | memory banks | none |
| Emberworks Forge | blacksmith and craft flavor | transformation forge | none |
| Market Lane | merchants and service stalls | marketplace / exchange | none |
| Guard Hall | civic order and gate watch | lawkeeper district | none |
| House Steps | first housing fantasy | civic population | none |
| Drain Gate | sewer / undercity hint | transition-like flow | none |
| Old Wall | city boundary visual | defense systems | none |

## Landmark Placement Intent

High Gate:

- north or upper edge
- should visually lead into Crown Plaza

Crown Plaza:

- center
- must have enough walking room and visual air

Market Lane:

- upper-right or right side
- close enough to plaza to feel civic, not isolated

Lantern Archive / Guard Hall:

- upper-left or inner civic quarter
- should read as official stone buildings

House Steps:

- lower-left
- walk-in house visual assembly applies

Drain Gate:

- lower-right edge
- should be intentionally placed, darker, and readable

## Presentation Rules

- A door-looking landmark does not grant door behavior.
- A sewer-looking landmark does not grant transition behavior.
- A market-looking landmark does not grant shop behavior.
- A guard-looking landmark does not create server NPC behavior.
- A house-looking landmark does not grant ownership or access.
