# High City NPC And Role Ideas

## Purpose

Extract useful role ideas from VaultCore professions and city districts, then translate them into grounded Akalynth NPC and role concepts.

These are visual/design ideas only.

## Source Role Families

VaultCore source material included role families such as:

- dream weaver
- pattern architect
- reflection guide
- flame walker
- evolution catalyst
- creative fire bearer
- codex keeper
- law seer
- prophecy reader
- convergence guide

Those names and mechanics are not imported directly. Akalynth should use simpler first-city roles.

## Role Boundaries

NPC-looking sprites do not create server NPCs.

Role ideas do not create:

- dialogue
- shops
- factions
- schedules
- combat
- pathing
- quest state
- spawns
- authority

## Future Review Questions

Before implementation, each role should answer:

1. Is it visual-only, dialogue-only, shop, quest, combat, or system authority?
2. Which server entity owns it?
3. Which protocol fields expose it?
4. Which receipt actions prove it?
5. Which map metadata places it?

Until those are answered, these remain ideas.
