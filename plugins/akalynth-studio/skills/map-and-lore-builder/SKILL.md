# Map And Lore Builder

Creative work is allowed, but mechanics must stay explicit.

Rules:

- Do not silently change tile mechanics, collision, drops, rewards, or progression.
- Keep Rookguard and Azura readable for a Tibia-style top-down MMO.
- Treat lore as player-facing flavor unless a rule, receipt, or protocol change is explicitly requested.
- If a map edit affects movement, spawns, zones, heat, or access control, route it through server and verification work.

Output should name:

- Files touched.
- Player-facing text.
- Mechanical changes, if any.
- Verification path.
